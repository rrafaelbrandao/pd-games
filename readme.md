# 🎮 PD Games - Plataforma de Jogos

## 🚀 Sobre o Projeto

O **PD Games** é um site institucional e de vitrine de jogos desenvolvido como parte de um projeto prático de desenvolvimento front-end. O sistema simula uma plataforma especializada em títulos de grande sucesso (como *Need for Speed*), oferecendo páginas detalhadas de produtos, seções informativas sobre a empresa e uma central de atendimento completa.

O projeto foi construído utilizando estritamente **HTML5 e CSS3 puros**, aplicando metodologias modernas de desenvolvimento, organização por blocos e uma identidade visual imersiva com tema escuro.

## ✨ Principais Funcionalidades

* **Página Inicial (Home):** Apresentação visual da marca e navegação rápida.
* **Catálogo de Produtos e Jogos:** Páginas dedicadas, incluindo páginas individuais para cada título na pasta dedicada de jogos, contendo detalhes técnicos, trailers, capturas de tela e requisitos.
* **Página Sobre a Empresa:** Histórico, valores e missão da marca no ecossistema de games.
* **Central de Atendimento (Contato):** Seção de suporte estruturada com cartões informativos (localização, e-mail e horário) e formulário interativo estilizado.
* **Design System Consistente:** Uso de paleta de cores personalizada (`#0b1118`, `#4B1F25`, `#c49a52`) e tipografia profissional via Google Fonts (*Cinzel* e *Montserrat*).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todas as páginas e formulários.
* **CSS3:** Estilização avançada, uso de **Flexbox** para layouts flexíveis e seletores estruturados.
* **Metodologia BEM (Block, Element, Modifier):** Padrão rigoroso de nomenclatura de classes para garantir escalabilidade e organização do código CSS.
* **Google Fonts:** Tipografia com as fontes `Cinzel` (títulos) e `Montserrat` (textos).

## ⚙️ Como Executar o Projeto

1. Clone ou baixe o repositório para a sua máquina.
2. Abra a pasta do projeto utilizando um editor de código (como o **VS Code**).
3. Utilize a extensão **Live Server** no VS Code para abrir o arquivo `index.html` no navegador, garantindo o carregamento correto de todos os caminhos relativos de imagens, vídeos e folhas de estilo.
